# makobot.com

Product site for **MakoBot** (Russell's AI memory tool, product of Mako Logics / MakoBytes). Handles marketing, license key issuance, the AI Skills Exchange marketplace, and the installer download flow.

## Stack
- **Framework:** Next.js (App Router). **Heads-up from AGENTS.md: this version has breaking changes — read `node_modules/next/dist/docs/` before writing Next.js code.**
- **DB:** Neon Postgres.
- **Hosting:** Vercel.
- **Auth:** Google OAuth (site sign-in), GitHub OAuth (Exchange claim flow).
- **DNS:** Cloudflare → Vercel.

## Key routes
- `/` — landing page (dark theme, 11 sections, Pixa images).
- `/get-key` — Google OAuth → license key → download.
- `/exchange` — AI Skills Exchange marketplace (listings, stacks, collections, requests, trending, profiles).
- `/exchange/[slug]` — individual listing detail page with Try-It Sandbox.
- `/exchange/user/[id]` — public user profile.
- `/admin` — admin dashboard (stats, charts, users, keys, analytics).
- `/admin/exchange` — moderation.
- `/admin/exchange/scrape` — GitHub + Gists scraper.
- `/admin/services` — shows current MakoBot build number (needs manual bump per release).
- `/api/download` — POST-only authenticated endpoint; reads `DOWNLOAD_URL` env var; returns GitHub release asset URL.
- `/llms.txt`, `/sitemap.xml`, `/robots.txt` — SEO + AI search surface.

## Build number convention
The admin services page at [app/admin/services/page.tsx](app/admin/services/page.tsx) displays the currently-shipped MakoBot desktop build. Bump this file whenever a new MakoBot build goes live on GitHub release v2.0.0. It's been the single most frequently-edited file on this repo — see recent commits like `53fb221`, `c1c289b`, `0a70e75`, `11d5f97`.
